## Visual gate decision

Two reproducible visuals are retained because they reduce the cost of reading the threshold structure:

1. `figures/parameter_regions.tex` — one-dimensional parameter map preserving the actual relative scale of the four thresholds `1/9`, `4/27`, `4/21`, `2/9`.
2. `tables/parameter_regions.tex` — compact region-by-region equilibrium/welfare summary.

Both are generated by `scripts/generate_outputs.py`; CI requires regeneration to leave the Git tree unchanged. No numerical calibration, arbitrary normalized plot, or decorative figure is included.

## Scope controls

- No visual labels the asymmetric profiles as the complete equilibrium set.
- `equilibrium welfare dominance` is used only on `[4/27,2/9)`.
- The interval `(1/9,4/27)` is labeled as failure of the reported symmetric profile, not as a full-game nonexistence region.
- The `t>0` rescaling is not described as robustness to general transportation technologies.
