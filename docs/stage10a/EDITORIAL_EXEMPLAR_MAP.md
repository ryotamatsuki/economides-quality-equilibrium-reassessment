## Coherent synthesis decisions

1. **One question / one object**: Does globally incentive-compatible quality choice preserve the reported symmetric endpoint candidate? This is answered by the *complete restricted-game pure-NE correspondence*. No competing headline theorem on planner welfare.
2. **Consistent notation**: λ=c/μ, δ=a1−a2, quality A=1/(3λ), B=1/λ; z reserved for consumer position and q for demand if needed. Display primitives once in Model; do not borrow E1's k for an externality or E3's U/t parameter.
3. **One proof hierarchy**: (i) price-continuation lemma with exact branch validity; (ii) headline characterization theorem; (iii) within proof: corner equilibria and interior necessity. Global logic visible in main text, routine arithmetic in supplement.
4. **No source imitation**: no source wording, diagram, or formulas carried across. Only general structural writing methods are adopted. Published comparator evidence is not novel-theorem evidence.
5. **Transitions**: source claim → primitives → piecewise price continuation → quality payoff → exhaustive NE set → intuition → limits. The LaTeX body should cross-reference any appendix exactly where proof is summarized.
6. **Conflicting approaches**: E1 gives only counterexamples; E2 gives exhaustive theorem. Choose **both** roles in sequence, since the present certified P04 is stronger than a counterexample. E3 outlines a further constructive equilibrium, but it is not imported because it would change the research target and has a different model.
7. **Formal-proof boundary**: analytic continuum-demand and pricing lemma are outside Lean; Lean formalizes quality NE iff for the derived reduced payoff only. State scaling x=λa, F=18λ²v>0 and case-domain connection. A short transparent note rather than substituting machine output for a specialist-readable proof.
